# 📊 Real-Time Analytics Dashboard

A modern analytics dashboard built using React and Vite for monitoring system metrics, reports, and performance data in real time.

---

## 🚀 Features

- User Authentication
- Admin Dashboard
- User Dashboard
- Analytics Visualization
- Reports Section
- Performance Charts
- Activity Tracking
- Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Spring Boot
- JWT Authentication

### Database
- PostgreSQL
