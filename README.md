# 📊 Real-Time Analytics Dashboard

A distributed backend analytics dashboard built using React, FastAPI, Spring Boot, Node.js, PostgreSQL, and MongoDB. The system provides real-time analytics monitoring, secure authentication, activity tracking, and performance visualization.

---

## 🚀 Features

* User Authentication (JWT)
* Role-Based Access Control (RBAC)
* Admin Dashboard
* User Dashboard
* Analytics Visualization
* Reports Management
* Activity Tracking
* CRUD Operations
* API Gateway Architecture
* Responsive UI

---

## 🏗️ System Architecture

Frontend (React)
↓
FastAPI Gateway
↓
├── Spring Boot Backend
│ └── PostgreSQL
│
└── Node.js Analytics Service
└── MongoDB

### Spring Boot Backend

mvn spring-boot:run
